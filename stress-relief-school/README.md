# ストレスリリーブ®︎スクール — 申込み用LP

Instagram・YouTube・公式LINEからの流入を「ストレスリリーブ®︎スクール受講相談」へ誘導するための、
日本語1ページ完結型LPです。ビルドツールを使わない静的HTML/CSS/JSで構成しています。

## 構成

```
stress-relief-school/
├── index.html      … LP本体（全16セクション、SEO/OGPメタタグ込み）
├── css/style.css   … スタイル（黒×ゴールド、モバイルファースト、1セクション1メッセージ）
├── js/config.js    … CTAリンク先の設定（ここを書き換えるだけでOK）
├── js/script.js    … CTAリンクの反映、スマホ固定CTA、控えめなスクロールイン演出
├── images/         … 本LP専用に最適化した画像（WebP＋JPEGフォールバック、Lazy Load対応）
├── favicon.svg     … ファビコン
└── README.md       … このファイル
```

## ローカルでの表示確認

```bash
cd amy-1p/stress-relief-school
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## 公開前に必ず差し替えていただきたい項目

### 1. CTAリンク先（最重要）

`js/config.js` の2つの値を、実際のURLに書き換えてください。

```js
window.SITE_CONFIG = {
  consultUrl: "https://forms.gle/xxxxxxxxx", // 受講相談フォームのURL
  lineUrl: "https://lin.ee/xxxxxxxxx"        // 公式LINEの友だち追加URL
};
```

これだけで、ページ内すべての「ストレスリリーブ®︎受講相談をする」ボタン（`.js-cta-consult`）と
「公式LINEで相談する」「LINE相談」ボタン（`.js-cta-line`）に一括反映されます。
スマホでは画面下部に固定表示される2つのボタンにも同様に反映されます。

### 2. ドメイン関連

`index.html` 内の `<link rel="canonical">` と OGP用URL（`og:url` / `og:image` / `twitter:image`）にある
`https://example.com/` を本番ドメインに変更してください。

### 3. フッターのリンク

「プライバシーポリシー」「特定商取引法に基づく表記」「お問い合わせ」（現在は仮リンク `#`）を、
実際のページURLに差し替えてください。

### 4. 受講料モデル試算の数値

「9. 受講料を費用で終わらせない考え方」セクションの単価・件数はサンプル値です。
実際の受講料・メニュー単価に合わせて `index.html` 内の該当箇所を調整してください
（法令遵守のため、モデル試算である旨・保証しない旨の注記は残したままにしてください）。

## 画像の差し替え方法

`images/` フォルダ内の各画像は WebP版（`.webp`）とJPEG版（`.jpg`）のペアで構成されています
（`<picture>` タグにより、対応ブラウザにはWebPを、非対応ブラウザにはJPEGを自動配信します）。

差し替える場合は、同じファイル名・同じ拡張子の組み合わせで両方とも上書きしてください。
推奨サイズ・画質の目安は以下の通りです。

- 横幅: 700〜1400px程度（表示サイズの実測に合わせて過度に大きくしない）
- 画質: JPEG 80前後 / WebP 76前後
- 各セクションの `<img>` の `width`/`height` 属性も、実際の画像サイズに合わせて更新してください（レイアウトシフト防止のため）

## デザイン意図

- メインカラー：`#0A0A0A`（黒）／`#111111`（チャコール）／`#D4AF37`・`#C89B3C`（ゴールド）／`#F7F3EA`（アイボリー）／`#FFFFFF`（白）
- 見出しに明朝体（Shippori Mincho）、本文にNoto Sans JPを使用し、美容スクールらしい専門性・高級感・信頼感を表現
- セクションごとに背景色（黒・チャコール・白・アイボリー）を切り替え、1セクション1メッセージを徹底
- 派手なアニメーションは使用せず、スクロールインもごく控えめ（`prefers-reduced-motion` にも対応）
- CTAボタンは常にゴールド系。スマホでは画面下部に固定表示（LINE相談／受講相談の2ボタン）
- 実績・投資回収に関する表現は、断定的な保証表現を避け、「モデル試算」「一つの目安」「保証するものではありません」を明記
